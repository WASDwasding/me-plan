# me-plan

韩国顶尖高校（延世大学 / 浦项工科大学）计算机硕士申请的个人进度看板。纯静态，没有后端，双击 `index.html` 就能打开。

主进程拆成 6 条并行支线。每条支线再拆成一级任务和最小叶子。叶子有三种状态，进度从叶子往上汇总。

## 进度怎么算

- 待完成 = 0，进行中 = 0.5，已完成 = 1
- 父节点进度 = 直接子节点进度的平均。多拆几条叶子，不会让这一支自动变重
- 总进度 = 六条支线进度的平均，跟每条支线里有多少叶子无关

页面上点击叶子，会按「待完成 → 进行中 → 已完成 → 待完成」切换，并立刻重算支线和总进度。

## 改任务

编辑 `js/data.js`。

- 改某一条的预设状态：改它的 `status`（`todo` / `active` / `done`）
- 新增叶子：在对应 `children` 里加一项，`id` 必须全局唯一
- 再拆一层：去掉 `status`，改成继续放 `children`
- 新增支线：照现有对象往 `branches` 追加，`code` 用来显示编号
- 想让某条更重要：给该节点加 `weight: 2`（正数，默认 1）

页面上点过的状态保存在本机 `localStorage`（键名 `me-plan.status.v1`），同一个 `id` 会覆盖文件里的预设。页脚「重置为代码预设」会清掉本机记录。换浏览器、换电脑，或清空站点数据后，会回到 `data.js` 的预设。

## 文件

- `index.html` 页面骨架
- `css/style.css` 布局和颜色
- `js/data.js` 目标、底色数据和任务树
- `js/app.js` 汇总、渲染、点击和本机保存
